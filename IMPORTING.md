# Импорт проекта из Roblox Studio

1. Открой актуальную опубликованную игру в Roblox Studio.
2. Выбери **File → Save to File As...** и сохрани копию в формате **Roblox XML Place (.rbxlx)**.
3. Не перезаписывай единственную резервную копию.
4. Запусти скрипт `tools/extract_rbxlx.py` из корня репозитория:
   `python3 tools/extract_rbxlx.py /путь/к/TruckSimulator2.rbxlx`
5. Скрипт сохранит найденные исходники Script, LocalScript и ModuleScript в `src/`, повторяя путь объектов Roblox.

Бинарный Place и XML Place следует хранить отдельно как резервные копии (при необходимости — через Git LFS или Releases). Не добавляй секретные ключи, токены и приватные данные.

После извлечения нужно вручную проверить структуру и ссылки на ресурсы. Rojo: см. `ROJO.md`. Проект Rojo собирается скриптом `tools/make_rojo_project.py` по фактической иерархии из `.rbxlx`, чтобы не потерять объекты и настройки Place.

**Внимание:** повторная выгрузка перезапишет файлы в `src/` версиями из Studio, включая переписанные скрипты. Выгружай в отдельную папку (`--output`) и сравнивай.
