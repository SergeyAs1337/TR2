# Фура Симулятор 2

Исходный репозиторий проекта Roblox.

## Структура

- `place/` — резервная копия исходного Place (RBXL/RBXLX; добавляется отдельно).
- `src/` — извлечённые исходники Lua-скриптов с сохранением иерархии объектов.
- `tools/` — вспомогательные инструменты импорта.
- `IMPORTING.md` — инструкция по подготовке исходников.

> Важно: извлечение скриптов из Place не переносит автоматически все модели, изображения, звуки и другие Roblox-ресурсы. Полная игровая сцена сохраняется в резервном файле Place.
